# French 74 (Le Vengeur du Peuple, L'Achille, Le Northumberland): provenance and modelling decisions

Original geometry generated from `spec.json` by the headless Blender kit; no
reference image, texture or third-party mesh is shipped.

**Fidelity, not a reconstruction.** One spec stands for the three French
seventy-fours in The Line of Battle. It is built like the [British 74](../british-74/PROVENANCE.md),
from L'Insurgente's spec, and keeps the French frigates' paint and flags so the
two sides read differently.

## Facts used

- About 53 m long and 14.6 m beam, the same as the British spec (the real Téméraire class was a little larger).
- 74 guns, with the same port layout as the British spec.

## Deliberate choices (not evidence)

- **Paint:** black with red-ochre bands and red port lids, as on L'Insurgente and Volontaire.
- **Flags:** the 1794 tricolour.
