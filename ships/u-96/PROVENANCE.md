# U-96 — game model provenance

Original generated geometry for the1942 Wolf Pack scenario. The name and TypeVII role come from `src/sim/scenarios.js`; the scenario rates guns as0, so this model deliberately has no counted deck cannon or funnel.

This is a class-inspired, approximate67m×6.2m game silhouette, not a measured U-96 reconstruction. It uses a low curved hull, rounded tower, two periscopes, deck casing and simple stern planes. Tower/rail details and underwater fittings are simplified for immersion. No third-party mesh, texture or traced archive drawing was used; no reference image is shipped.
