# RNS Shahin provenance

Fictional original game asset for the Strait of Qamar. No real-country ship, archive drawing, third-party mesh, or protected artwork was used.

- Intent: plausible near-future red-side missile destroyer, about 140-150 m, visually distinct from a Blue/US integrated-mast silhouette.
- Deliberate visual choices: conventional pole/lattice-style foremast, two separated funnels, one visible fore gun, angled outboard missile-canister banks amidships, and a simple aft helicopter deck area.
- Accuracy tier: best-guess fictional silhouette for quick gameplay readability, not historical or national-technical accuracy.
- Armament note: scenario ammunition/defense values are abstract. `spec.guns = 1` is only the one visible fore turret; visible canister/tube count is decorative and not literal ammo.
- Provenance: authored entirely from repo shipkit primitives in `ships/rns-shahin/spec.json`.

Launcher cradles and mast supports are simplified original fittings, seated into the deck or existing bridge blocks for readable, grounded game geometry.
